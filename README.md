## Earth, weather and climate

| Page | Paper | What to borrow |
| --- | --- | --- |
| [MMEarth-Bench](https://mmearth-bench.com/) | MMEarth-Bench: Global Model Adaptation via Multimodal Test-Time Training (ECCV 2026) | Embedded dataset explorer with zoom, hover and filters; an animated GIF that explains the method; benchmark tables; copy-ready download commands |
| [RainODE](https://seongye.github.io/rainode/) | RainODE: Continuous-Time Precipitation Forecasting with Latent Neural ODEs (ECCV 2026) | Short and focused: three figures that each make one claim, from method to results to latent trajectories |
| [JWS](https://compvis.github.io/jws/) | Just Weather Scoring: Efficient End-to-End Nowcasting with Distributional Diffusion (arXiv 2026) | Forecast videos that play in sync, with one slider that reveals ground truth across every panel and a lead-time counter; results tables in the page with a toggle for a second dataset; copy-BibTeX button |
| [FREUD](https://compvis.github.io/weather-rf/) | Probabilistic Precipitation Nowcasting with Rectified Flow Transformers (CVPR 2026) | TL;DR as four labelled points; video grids of ground truth, ensemble mean and single ensemble members; sliders that compare the forecast with two baselines on the same storms |
| [AnySat](https://gastruc.github.io/anysat) | AnySat: An Earth Observation Model for Any Resolutions, Scales, and Modalities (CVPR 2025) | Quick-start code snippet; a strip of key numbers (datasets, sensors, resolution range); light and dark theme; copy-BibTeX button |
| [TerraMind](https://ibm.github.io/terramind/) | TerraMind: Large-Scale Generative Multimodality for Earth Observation (ICCV 2025) | Before/after sliders between generated modalities; live download counter; section titles written as questions |
| [WeatherBench 2](https://sites.research.google/gr/weatherbench/) | WeatherBench 2: A benchmark for the next generation of data-driven global weather models (JAMES 2024) | Headline scorecards against a reference model; interactive plot of each metric against lead time where you toggle models; FAQ that defines every metric |
| [DiffusionSat](https://www.samarkhanna.com/DiffusionSat/) | DiffusionSat: A Generative Foundation Model for Satellite Imagery (ICLR 2024) | One section and figure per task; an explicit Limitations section; data link next to the paper and code links |
| [OpenStreetView-5M](https://osv5m.github.io/) | OpenStreetView-5M: The Many Roads to Global Visual Geolocation (CVPR 2024) | Image carousel that credits each photo's contributor and country; density maps of the splits; short "Key takeaways" section |
| [ClimateNeRF](https://climatenerf.github.io/) | ClimateNeRF: Extreme Weather Synthesis in Neural Radiance Field (ICCV 2023) | Buttons choose the weather effect, scene and baseline for one split-screen video comparison; user-study chart with tabs |
| [Sat2Density](https://sat2density.github.io/) | Sat2Density: Faithful Density Learning from Satellite-Ground Image Pairs (ICCV 2023) | Buttons switch between ablation videos; drag-to-compare videos against prior work; dated change log at the top |

## ML, vision and graphics

| Page | Paper | What to borrow |
| --- | --- | --- |
| [VISTA](https://vista-research.github.io/) | VISTA: A Visual Harness for Reasoning in an Interactive World (MIT, 2026) | Recorded game replays, tabs to switch between models, and one game state shown as text, 2D image and 3D render |
| [CAT3D](https://cat3d.github.io/) | CAT3D: Create Anything in 3D with Multi-View Diffusion Models (NeurIPS 2024) | 3D viewer embedded in the page; widget to pick a baseline and scene for comparison; one-line TL;DR |
| [Marigold](https://marigoldmonodepth.github.io/) | Marigold: Repurposing Diffusion-Based Image Generators for Monocular Depth Estimation (CVPR 2024) | Gallery of image/depth sliders; one row of buttons for the demo, tutorial and Colab |
| [SMERF](https://smerf-3d.github.io/) | SMERF: Streamable Memory Efficient Radiance Fields for Real-Time Large-Scene Exploration (SIGGRAPH 2024) | Scene thumbnails that open a real-time viewer in the browser; comparison sliders labelled with each method's model size |
| [3D Gaussian Splatting](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/) | 3D Gaussian Splatting for Real-Time Radiance Field Rendering (SIGGRAPH 2023) | Before/after sliders against three baselines and ground truth; download links that state file sizes |
| [Zip-NeRF](https://jonbarron.info/zipnerf/) | Zip-NeRF: Anti-Aliased Grid-Based Neural Radiance Fields (ICCV 2023) | Split-screen video against a baseline that isolates the one problem the paper solves; notebook link next to the code |
| [LERF](https://www.lerf.io/) | LERF: Language Embedded Radiance Fields (ICCV 2023) | Scene strip that loads a video player with a toggle between RGB and the model's output; TL;DR under the title |
| [DreamFusion](https://dreamfusion3d.github.io/) | DreamFusion: Text-to-3D using 2D Diffusion (ICLR 2023) | Prompt picker that swaps the result video; a separate searchable gallery page; downloadable meshes |
| [HyperNeRF](https://hypernerf.github.io/) | HyperNeRF: A Higher-Dimensional Representation for Topologically Varying Neural Radiance Fields (SIGGRAPH Asia 2021) | Interactive 3D figures that explain the core idea; carousel of result videos with depth |
